# Simon Says Game 🎮

A fun and interactive memory game built using HTML, CSS, and JavaScript.

## 🎯 About the Game

Simon Says is a memory-based game where the player must remember and repeat
a sequence of colored buttons. The sequence becomes longer with each level,
making the game progressively more challenging.

## 🕹️ How to Play

1. Press any key to start the game.
2. Watch the sequence of colors shown by the game.
3. Click the buttons in the same order as the sequence.
4. Each successful round adds one more color to the sequence.
5. If you click the wrong button, the game ends.
6. Press any key to restart and try to beat your previous score.

## ✨ Features

- Interactive color buttons
- Randomly generated sequences
- Increasing difficulty with each level
- Score/level tracking
- Game-over detection
- Restart functionality
- Button animations and visual feedback

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
